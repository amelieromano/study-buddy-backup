# Study Buddy Finder

Find someone at UCL to study with. A first simple version, built live at Vibecoding 101 (UCL AI Society × Claude Builder Club).

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## What's in it

See [SPEC.md](SPEC.md) for the flow: a home page, a page of students who are free to study, a filter by course and a Nudge button. Fake data only for now: no login or database yet.
